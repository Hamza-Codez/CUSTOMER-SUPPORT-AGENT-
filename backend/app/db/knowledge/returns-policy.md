# Returns Policy

How to send an item back to Aeron Home Goods.

## How to start a return {#starting-a-return}

To return an item, contact support with your order number. We email a prepaid
return label. Returns are free for faulty goods; for change-of-mind returns a 4.99
label fee is deducted from the refund.

Large items such as desks are collected by a two-person carrier team rather than
returned by post, and a collection slot is booked with you by email.

## Condition of returned items {#return-condition}

Returned items must be complete, including fixings, cables and manuals. Items
returned incomplete may receive a partial refund reflecting the missing parts.
